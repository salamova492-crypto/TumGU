# Здоровый образ жизни!

Веб-приложение для записи к врачам с регистрацией пользователей, аутентификацией и административной панелью.

## Функциональность
- Регистрация новых пользователей с валидацией данных
- Аутентификация пользователей с проверкой логина/пароля
- Просмотр специальностей врачей
- Запись к врачам с проверкой доступности
- Управление записями (просмотр, отмена)
- Административная панель для добавления врачей
- Разграничение прав доступа (пользователи и администраторы)

## Технические требования
- Валидация на клиентской и серверной сторонах
- Хранение паролей в хеш-формате (md5)
- Ограничения по времени для отмены записей
- Защита от несанкционированного доступа
- Удобный интерфейс для всех типов пользователей

## Структура проекта
- `includes/` - вспомогательные PHP файлы (подключение к БД, сессии)
- `css/` - стилевые файлы
- `js/` - JavaScript файлы
- `index.php` - главная страница
- `register.php` - форма регистрации
- `login.php` - форма входа
- `dashboard.php` - личный кабинет
- `admin_panel.php` - административная панель
- `make_appointment.php` - запись к врачу
- `my_appointments.php` - мои записи
- `cancel_appointment.php` - отмена записи
- `specialties.php` - специальности врачей
- `logout.php` - выход из системы

## Установка
1. Убедитесь, что у вас установлены PHP и MySQL
2. Настройте веб-сервер (Apache/Nginx) для работы с PHP
3. Импортируйте базу данных (таблицы создаются автоматически при первом запуске)
4. Измените параметры подключения к БД в `includes/db_connect.php` при необходимости
5. Откройте главную страницу в браузере
